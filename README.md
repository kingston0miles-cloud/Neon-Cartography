# Neon-Cartography
Сервис для создания карт современных/киберпанк/НФ мегаполисов/городов/деревень/поселений
# Руководство пользователя «НЕОН-КАРТОГРАФ»

Полное практическое руководство по генератору городов. От первого запуска до экспорта готовой карты.

---

## 1. Что это и для чего

**НЕОН-КАРТОГРАФ** — браузерный генератор процедурных карт городов в неоново-киберпанк-стилистике. Работает полностью офлайн, в одном HTML-файле. Не требует установки, регистрации, сервера.

**Что умеет:**
- Генерировать город целиком: море, реки, горы, поля, районы, улицы, здания, парки, свалки, особые здания.
- Считать население — общее и по районам.
- Строить города разной формы: круглые, вытянутые вдоль трассы, «сетка».
- Давать процедурные имена всему: районам, улицам, рекам, паркам, монументам.
- Работать с тремя встроенными «языковыми библиотеками» (неон-нуар, славянская, техно-утопия) и загружать свои.
- Рисовать вручную: насыпать остров, проложить реку, нарисовать район, поставить памятник.
- Экспортировать в PNG (до 8000 px) и PDF (A4–A0, до 300 dpi).
- Сохранять проекты в JSON и автоматически — в браузер.

**Кому подойдёт:** гейм-дизайнерам, писателям, авторам настолок, иллюстраторам, просто любителям карт.

---

## 2. Первый запуск

1. Скачай файл `Неон-Картограф.html`.
2. Открой его двойным щелчком в браузере. Рекомендуется **Chrome**, **Edge** или **Firefox** последних версий.
3. Подожди 2–3 секунды — загрузятся шрифты (Exo 2, Russo One, Share Tech Mono). Сначала будет пусто, потом появится карта.
4. Если это первый запуск — сгенерируется **случайный город** автоматически.
5. Если раньше уже открывал — восстановится **последний проект** из локального хранилища браузера.

> **Совет.** Не очищай «данные сайта» и localStorage, если хочешь сохранить автосейв. Лучше периодически жать **Экспорт → Сохранить проект** и складывать JSON-файл в надёжное место.

## 3. Интерфейс: где что находится

```
┌──────────────────────────────────────────────────────────────┐
│  [Логотип]  [Название города]  [🎲 Новый] [⛶ Фитинг] [↶] [↷]  │  ← Шапка
├────┬────────────────────────────────────────┬───────────────┤
│ И  │                                        │               │
│ Н  │                                        │   ПАНЕЛЬ      │
│ С  │           ХОЛСТ С КАРТОЙ               │   (вкладки    │
│ Т  │                                        │   и настройки)│
│ Р  │                                        │               │
│ У  │                                        │               │
│ М  │  [HUD: масштаб, население, координаты] │               │
├────┴────────────────────────────────────────┴───────────────┤
│                          [Карточка объекта, если что-то     │
│                           выделено]                          │
└──────────────────────────────────────────────────────────────┘
```

### 3.1. Шапка (сверху)

| Элемент | Что делает |
|---|---|
| **Логотип «НЕОН-КАРТОГРАФ»** | Просто украшение |
| **Поле «Название города»** | Введи любое имя — оно попадёт на плашку экспорта |
| **🎲 (кнопка генерации)** | Создать новый случайный город с новым зерном |
| **⛶ (фитинг)** | Показать всю карту целиком (вписать в экран) |
| **↶ Отменить** | Ctrl+Z — откатить последнее действие |
| **↷ Повторить** | Ctrl+Shift+Z — вернуть отменённое |

### 3.2. Левая панель — инструменты

Вертикальный ряд иконок. Наведи курсор — появится подсказка.

**Навигация и природа:**
- **Курсор** — выбор и правка объектов. Основной инструмент.
- **Море** — кисть добавить воду.
- **Суша** — кисть убрать воду (нарисовать сушу).
- **Горы** — кисть поднять рельеф.
- **Равнина** — кисть выровнять горы.
- **Сгладить** — кисть размыть резкие переходы воды/гор.
- **Река** — рисуешь ломаную → получается река.

**Город:**
- **Район** — клики задают полигон района.
- **Дорога** — рисуешь путь дороги.
- **Рельсы** — то же, но для железной дороги.
- **Улица** (подпись) — клик по улице → надпись вдоль неё.
- **Текст** — свободная надпись в любом месте.
- **Значок** — поставить якорь/корабль/башню/станцию.

**Объекты:**
- **Парк** — кисть рисовать зелёные зоны.
- **Свалка** — кисть рисовать пустыри и полигоны.
- **Объект** — поставить особое здание (монумент, капитолий и т.п.).
- **Рамка** — выделить прямоугольную область для PNG-экспорта.

### 3.3. Правая панель — вкладки

Семь вкладок сверху панели:

| Вкладка | Что внутри |
|---|---|
| **Генерация** | Параметры генерации нового города |
| **Ландшафт** | Кисти, слои, рисование рек |
| **Город** | Районы, дороги, значки, особые здания, кисти |
| **Названия** | Библиотеки имён и регенерация |
| **Цвета** | Палитры, эффекты, слои |
| **Подписи** | Шрифты, авто-расстановка имён |
| **Экспорт** | PNG, PDF, сохранение проекта |

Ниже вкладок — **карточка объекта**. Появляется, когда что-то выделено на карте.

### 3.4. HUD (слева внизу холста)

Три числа:
- **Масштаб** — например, `100%`.
- **Население города** — например, `487 320 чел.`
- **Координаты курсора** — например, `1200, 830`.

### 3.5. Панель под холстом (drawbar)

Появляется, когда рисуешь что-то кистью или ломаной. Три кнопки:
- **Назад** — убрать последнюю точку.
- **Готово (Enter)** — завершить рисование.
- **Отмена (Esc)** — отменить целиком.

## 4. Базовый сценарий: сгенерировать город за 30 секунд

1. Открой вкладку **Генерация**.
2. Выбери **тип поселения**:
   - **Мегаполис** — до 3 млн населения, 9 районов, много зданий.
   - **Город** — до 300 тыс., 6 районов.
   - **Деревня** — до 10 тыс., 2 района, без магистралей.
3. **Форма города** — оставь «Круглый» или попробуй «Вытянутый».
4. **Местность** — «Побережье» (самый живописный вариант).
5. **Целевое население** — поставь, сколько хочешь.
6. Нажми **«Сгенерировать»**.

Через 2–4 секунды появится готовый город. Если что-то не нравится — нажми 🎲 или **«Сгенерировать»** с новым зерном.

## 5. Вкладка «Генерация» — все параметры

### 5.1. Тип поселения

Три кнопки-таблетки. Влияет на:
- Размер карты (1000×1150 / 1800×2050 / 2400×2760 px).
- Число районов.
- Количество дорог, магистралей, ж/д.
- Плотность ферм вокруг.

### 5.2. Местность

| Вариант | Что получается |
|---|---|
| **Побережье** | Море с одной стороны, пляжи, порт |
| **Бухта** | Море врезается «языком» |
| **Река через город** | Русло реки пересекает город |
| **Озеро** | Круглый водоём в центре |
| **Равнина без воды** | Сухой континентальный город |

### 5.3. Где море

Появляется только для «Побережье» и «Бухта». Варианты: случайно, справа, слева, сверху, снизу.

### 5.4. Форма города

- **Круглый** — классическая округлая застройка.
- **Вытянутый** — эллипс вдоль берега.
- **Линейный (трасса)** — узкая полоса вдоль главной дороги.
- **Сетка** — квадратный город с прямоугольными кварталами.

### 5.5. Горные хребты (0–3)

Сколько горных массивов сгенерировать. 0 — ровная местность. 3 — гористый рельеф.

### 5.6. Реки (0–3)

Сколько рек протекает через город. 0 — без рек. 3 — три русла.

### 5.7. Размер квартала (10–40)

Больше — крупные кварталы с редкой сеткой. Меньше — плотная мелкая нарезка.

### 5.8. Число районов (1–14)

Сколько административных единиц. Больше районов — сложнее структура, но каждый меньше.

### 5.9. Поля вокруг (0–60)

Сколько фермерских полей разбросать по карте вне города. 0 — плотная пустошь, 60 — деревенский ландшафт.

### 5.10. Целевое население

Желаемое население. От **500** до **3 000 000** человек.

**Важно:** если районов мало, или они мелкие, город не сможет вместить целевое население. Реальное население показывается под ползунком — например «На карте: 487 320 (цель 500 000)».

### 5.11. Зерно (seed)

Число, определяющее генерацию. **Одно и то же зерно = один и тот же город.** Скопируй число, чтобы вернуться к этому городу позже.

Кнопка **«Случайное»** — генерирует новое зерно.

### 5.12. Кнопки действий

| Кнопка | Что делает |
|---|---|
| **Сгенерировать** | Создать новый город. Цвета и стиль сохраняются, население/площадь — новые |
| **Применить к текущему городу** | Не пересобирать карту, а только изменить население (и плотность зданий) |
| **Пересобрать улицы** | Оставить районы, но дать им новые улицы (новое зерно) |
| **Новые названия районов** | Только переименовать районы |

## 6. Вкладка «Ландшафт» — рисование рельефа

### 6.1. Кисть ландшафта

В левой панели выбери одну из кистей:

| Инструмент | Что делает | Цвет обводки курсора |
|---|---|---|
| **Море** | Добавляет воду | Бирюзовый |
| **Суша** | Убирает воду | Оранжевый |
| **Горы** | Поднимает рельеф | Фиолетовый |
| **Равнина** | Понижает рельеф | Оранжевый |
| **Сгладить** | Размывает переходы | Белый |

**Как пользоваться:**
1. Выбери кисть.
2. В правой панели выставь **радиус** (10–300) и **силу** (0.1–1).
3. Зажми левую кнопку и води по карте.

Карта обновляется на лету. После отпускания — финальная перерисовка всех линий через 1–2 секунды.

### 6.2. Быстрые действия

- **Убрать всю воду** — мгновенно высушить карту.
- **Убрать горы** — выровнять рельеф.

### 6.3. Реки

- Ползунок **«Ширина новой реки»** — задаёт ширину.
- Кнопка **«Нарисовать реку»** — включает инструмент.

**Как рисовать реку:**
1. Клик — точка.
2. Ещё клики — изгибы.
3. Двойной клик или **Enter** — готово.

### 6.4. Слои

Чекбоксы включения/выключения слоёв:
- Море и побережье
- Горы
- Реки
- Поля
- Парки
- Свалки
- Здания
- Подписи объектов

Отключение слоя не удаляет данные, только прячет.

## 7. Вкладка «Город» — районы, дороги, объекты

### 7.1. Новый район

1. Выбери **тип района**:
   - Центр, Деловой квартал, Жилой район, Промзона, Порт, Трущобы, Парк, Пригород, Технопарк, Кладбище.
2. Нажми **«Нарисовать район»**.
3. Кликай вершины полигона.
4. Двойной клик — готово.

Новый район **перекрывает** старые: улицы под ним пересоздаются.

### 7.2. Список районов

Показывает все районы с цветными маркерами. Клик по имени — выделить район на карте и открыть карточку.

### 7.3. Дороги и рельсы

- **Тип новой дороги**: магистраль, проспект, улица.
- **«Нарисовать дорогу»** / **«Нарисовать рельсы»** — клики по точкам.

### 7.4. Особые здания

| Тип | Где ставить |
|---|---|
| **Монумент** | Центр, парк |
| **Капитолий** | Центр (один на город — уже стоит в центре) |
| **Правительство** | Центр, деловой квартал, технопарк |
| **Храм** | Жилой, пригород, центр |
| **Стадион** | Жилой, пригород, технопарк |
| **Достопримечательность** | Почти везде |

**Как поставить:** выбери тип → нажми **«Поставить объект»** → клик по карте.

Если ставишь не в подходящий район — приложение предупредит, но не запретит.

### 7.5. Значки

- Якорь, Корабль, Точка интереса, Вышка, Станция.
- Аналогично: выбери тип → кнопка → клик.

### 7.6. Кисти объектов

- **Парк** — рисовать зелёные зоны.
- **Свалка** — рисовать пустыри и полигоны.

Действие: зажми и води. Отпусти — фиксация.

Кнопки **«Убрать все парки»** и **«Убрать все свалки»** — полная очистка.

### 7.7. Видимость слоёв

Полный список слоёв (дублируется с вкладкой «Ландшафт», но тут только городские).

## 8. Вкладка «Названия» — библиотеки имён

### 8.1. Активная библиотека

Показывает, какая сейчас работает. По умолчанию — **«Неон-нуар»**.

### 8.2. Встроенные библиотеки

- **Неон-нуар** — киберпанк-стилистика. «Стальной Посад», «Улица Кузнецов», «Некрополь».
- **Славянский** — «Стрелецкая Слобода», «Улица Кузнецов», «Река Ока», «Княжий Двор».
- **Техно-утопия** — «Киберполис», «Центральный Хаб», «Линия Инженеров».

Клик по пресету — применить ко всем названиям текущего города. Планировка не меняется, только имена.

### 8.3. Своя библиотека

- **Сохранить библиотеку** — выгрузить текущую в JSON.
- **Загрузить свою библиотеку** — подсунуть свой файл.

Формат описан в `neon-library-doc.md` (см. отдельный документ). Есть готовый промпт для нейросети: скопируй его вместе с референсами — получишь библиотеку под свой сеттинг.

### 8.4. Регенерация имён

| Кнопка | Что делает |
|---|---|
| **Перегенерировать все имена** | Все имена меняются на новые (то же зерно) |
| **Регенерировать с новым зерном** | Все имена меняются + случайное зерно |
| **Случайное имя района / улицы / реки** | Показывает в toast одно имя (для проверки библиотеки) |

## 9. Вкладка «Цвета» — палитры и эффекты

### 9.1. Готовые палитры

- **Неон-нуар** — классический киберпанк (бирюза, розовый, фиолетовый).
- **Синтвейв** — ярко-розово-голубой ретро-футуризм.
- **Майами-вайс** — розовый + бирюзовый + жёлтый.
- **Янтарный терминал** — всё в охре.
- **Зелёный фосфор** — как старый монитор.
- **Дождь и неон** — синие тона.
- **Синька** — монохромный чертёж.

Клик — мгновенная смена всех цветов.

### 9.2. Цвета элементов

Можно тонко настроить **каждый** цвет:
- Фон, вода, глубины, берег, реки, горы.
- Поля, фермы, магистрали, проспекты, улицы, ж/д.
- Названия, подписи, значки, корабли.

### 9.3. Цвета типов районов

Отдельный цвет для каждого типа (10 штук). Здесь же можно изменить **цвет конкретного района** — но это уже в его карточке (см. §11).

### 9.4. Свечение и эффекты

| Ползунок | Что делает |
|---|---|
| **Неоновое свечение** | Сила глоу-эффекта на линиях |
| **Толщина линий** | Общая жирность всех контуров |
| **Подкраска районов** | Полупрозрачный цвет поверх районов |
| **Скан-линии** | Горизонтальные помехи, как на старом CRT |
| **Зерно плёнки** | Шумовая текстура |
| **Виньетка** | Затемнение по краям |

Ставь по вкусу. Все эффекты необязательны — выставь всё в 0 для чистого чертежа.

## 10. Вкладка «Подписи»

### 10.1. Показ

- **Названия районов** — включить/выключить подписи.
- **Названия улиц и надписи** — то же для улиц.
- **Названия магистралей и путей** — для дорог.

### 10.2. Шрифт

- **Exo 2 — техно** (по умолчанию).
- **Russo One — плакатный**.
- **Share Tech Mono — моно**.

### 10.3. Масштаб подписей

0.5–2.5×. Универсальный множитель всех надписей.

### 10.4. Названия улиц

- **Сколько расставить** — сколько надписей сгенерировать на карте.
- **«Расставить названия»** — сгенерировать.
- **«Убрать все»** — очистить все подписи.
- **Инструмент «Улица»** — ручная установка: клик по улице → имя вдоль неё.
- **Свободный текст** — надпись в любом месте.

## 11. Работа с объектами — карточки

Когда выделен какой-то объект (клик по нему **«Курсором»**), снизу панели появляется **карточка**.

### 11.1. Карточка района

| Поле | Что значит |
|---|---|
| **Название** | Имя района |
| **Тип района** | Смена типа меняет застройку |
| **Цвет района** | Переопределить цвет |
| **Планировка** | Сетка / извилистая / радиальная |
| **Плотность застройки** | 0–100% — как плотно стоят здания |
| **Население района** | Считается автоматически |
| **Размер квартала** | 8–60 — крупнее/мельче |
| **Вытянутость кварталов** | 1–2.4 — квадраты или прямоугольники |
| **Угол сетки** | 0–180° — поворот решётки улиц |
| **Извилистость** | 0–1.6 — насколько кривые улицы |
| **Переулки** | 0–1 — плотность мелких проходов |
| **Парки и скверы** | 0–1 — сколько зелени внутри |
| **Рваный край** | 0–1 — насколько неаккуратная граница |
| **Размер названия** | 0.4–2.5× |
| **Показывать название** | Вкл/выкл подпись |

**Кнопки:**
- **Новая раскладка** — новое зерно, другие улицы.
- **Новое имя** — случайное имя.
- **Сбросить метку** — вернуть позицию имени в центр.
- **PNG района** — экспорт отдельной картинки.
- **Удалить** — удалить район.

**Как править границы:**
- **Тянуть за квадратики** — двигать вершины.
- **Двойной клик по границе** — добавить точку.
- **Двойной клик по точке** — удалить.
- **Тянуть название** — сдвинуть подпись.

### 11.2. Карточка дороги

- **Название**, **Тип** (магистраль / проспект / улица / ж/д), **Положение названия**.

### 11.3. Карточка реки

- **Название**, **Ширина**.

### 11.4. Карточка парка или свалки

### 11.5. Карточка особого здания (значка)

- **Тип**, **Название** (для особых типов), **Показывать подпись**, **Размер**, **Поворот**.

Кнопки:

- **PNG рамки** — только область, выделенная инструментом «Рамка».

### 12.3. Рамка для экспорта

1. Инструмент **«Рамка»** (левая панель).
2. Обведи прямоугольник.

### 12.4. Проект

- **Сохранить проект** — JSON со всем: ландшафт, районы, дороги, подписи, цвета, библиотека имён.
- **Загрузить проект** — прочитать ранее сохранённый JSON.

## 14. Сценарии использования

### 14.1. «Мне нужен Нью-Йорк»

1. Генерация → Мегаполис.
2. Местность → Побережье, море справа.
3. Форма → **Сетка (NYC)**.
4. Сгенерировать.

Получишь квадратный город с прямыми кварталами и без кольцевой дороги.

### 14.2. «Город вдоль берега»

1. Генерация → Город.
2. Местность → Побережье, море слева.
3. Форма → **Вытянутый**.
4. Сгенерировать.

Город вытянется вдоль берега, главная магистраль пойдёт параллельно морю.

### 14.3. «Город-утопия на Луне»

1. Названия → **Техно-утопия**.
2. Цвета → **Синька** или **Зелёный фосфор**.
3. Ландшафт → убрать всю воду, убрать горы.
4. Генерация → Местность «Равнина без воды», форма «Круглый».

### 14.4. «Средневековый город в славянском стиле»

1. Названия → **Славянский**.
2. Цвета → **Янтарный терминал**.
3. Генерация → Деревня или Город, местность «Река через город».

### 14.5. «Нарисовать остров с нуля»

1. Ландшафт → **Море** → закрась всё.
2. **Суша** → нарисуй контур острова.
3. **Горы** — пара вершин в центре.
4. Кисть **Парк** — лесные массивы.
5. Кисть **Свалка** — мусорные полигоны по краю.
6. Город → **Нарисовать район** — 2–3 района.
7. Подписи → **Расставить названия**.

## 15. Частые проблемы

| Проблема | Что делать |
|---|---|
| **Карта не отображается** | Открой консоль (F12) → посмотри ошибки. Скорее всего, не догрузились шрифты — обнови страницу. |
| **Город не генерируется** | Проверь консоль. Возможно, зерно слишком большое (>2^31). Сбрось на 12345. |
| **Всё выключено, карта пустая** | Проверь «Ландшафт → Слои» — все чекбоксы. Возможно, что-то случайно отключено. |
| **Долго тянется генерация** | Мегаполис на слабом устройстве занимает 3–5 секунд. Дождись окончания. Не кликай повторно. |
| **Файл не загружается** | Проверь, что JSON валидный (открой в текстовом редакторе). Библиотека имён валидируется отдельно. |
| **Экспорт PDF падает** | Уменьши разрешение (100 dpi) или формат листа (A4). |
| **Имена пустые** | Скорее всего, загружена невалидная библиотека. Нажми «Неон-нуар» в «Названия», чтобы вернуть дефолт. |
| **После загрузки проекта карта пустая** | Возможно, проект сохранён из очень старой версии. Открой консоль — если `ReferenceError`, файл несовместим. |
| **Кнопка Undo не работает** | Стек ограничен 20 шагами. Старые действия недоступны. |
| **HUD показывает 0 чел.** | Целевое население = 0 или слишком мало районов для такого населения. Проверь «Генерация → Целевое население». |

## 16. Советы и трюки

1. **Одно зерно = один город.** Запиши понравившееся зерно — вернёшься к тому же городу. Кнопка «Случайное» в «Генерация → Зерно».

2. **Не бойся рисовать поверх.** Генератор — черновик. Кисти ландшафта быстро превращают случайный город в конкретное место.

3. **Район под районом не появляется.** Если рисуешь новый район поверх старого — старый исчезнет под новым.

4. **Библиотека имён — главный инструмент атмосферы.** Смена «Неон-нуар» → «Славянский» делает из киберпанк-города фэнтези-поселение без пересборки геометрии.

5. **Скриншот вместо экспорта.** Правый клик по холсту → «Сохранить изображение как». Быстрый способ показать карту другу.

6. **Перед сложными правками — жми Ctrl+Z часто.** Стек небольшой (20), но если делать пошагово — откатишь всё.

7. **Виньетка и скан-линии — в типографию только для настроения.** Для чистого чертежа выставь всё в 0 в «Цвета → Свечение и эффекты».

8. **Экспорт PDF > 200 dpi** — для типографии. **100 dpi** — для черновика.

9. **Своя библиотека имён — через промпт.** Открой `NAME-LIBRARY-FORMAT.md`, раздел 9, скопируй промпт в ChatGPT/Claude с референсами — получишь готовый JSON для загрузки.

10. **Автосохранение ≠ надёжное.** Раз в полчаса жми **«Сохранить проект»**, чтобы JSON лежал на диске.

## 17. Ограничения текущей версии

- **Только русский интерфейс.** Библиотеки имён поддерживают `lang`, но UI — один язык.
- **Только прямоугольные здания.** Полигональные (L-формы, ангары) — в планах.
- **Нет экспорта SVG.** Только PNG и PDF.
- **Нет кварталов как отдельной сущности.** Район — целая единица.
- **Свалка — не район.** Отдельный blob-объект, кисть и генерация.
- **Население — оценка, не симуляция.** Считается по площади × плотности × типу.
