## 1. Что это и для чего

НЕОН-КАРТОГРАФ — браузерный генератор процедурных карт городов в неоново-киберпанк-стилистике. Работает полностью офлайн, в одном HTML-файле. Не требует установки, регистрации, сервера.

### Что умеет

- Генерировать город целиком: море, реки, горы, поля, районы, улицы, здания, парки, свалки, особые здания.
- Считать население — общее и по районам.
- Строить города разной формы: круглые, вытянутые, кластерные, «сетка».
- Давать процедурные имена всему: районам, улицам, рекам, паркам, монументам, городам.
- Работать с тремя встроенными «языковыми библиотеками» и загружать свои — в формате v1 (словарный) или v2 (словарный + слоговый).
- Использовать контекст места: имя улицы в порту отличается от имени улицы в трущобах.
- Генерировать базовые топонимы слоговым методом (города, реки).
- Рисовать вручную: насыпать остров, проложить реку, нарисовать район, поставить памятник.
- Экспортировать в PNG (до 8000 px) и PDF (A4–A0, до 300 dpi).
- Сохранять проекты в JSON и автоматически — в браузер.

Кому подойдёт: гейм-дизайнерам, писателям, авторам настолок, иллюстраторам, просто любителям карт.

## 2. Что нового в версии 2.0

Относительно предыдущей версии:

### 2.1. Расширенный движок имён

- **Формат библиотек v2.** Новый формат с опциональной секцией `syllables`. Старые библиотеки (v1) продолжают работать без изменений.
- **Слоговый слой.** Для экзотических языков, где словарь ограничен или отсутствует. Два способа описания: `onset + nucleus + coda` (точный) или `recipes + C + V` (компактный).
- **Контекст для всего.** Раньше контекст был только у районов. Теперь у улиц, рек, парков, монументов, дорог — тоже. Улица в порту получает «Морскую» через `{terrain_f}`, улица в трущобах — «Кривую» через `{age_m}`, монумент в центре — «Центральный» через `{rank_m}`.
- **Расширенные словари.** Прилагательных втрое больше, профессий — вчетверо, добавлены редкие и узкоспециальные слова.
- **Управление слогами в UI.** Кнопки «Выключить слоги» / «Включить слоги» и «Слоги только для улиц» / «Слоги для городов и рек» прямо во вкладке «Названия».
- **Индикатор формата.** Показывает, библиотека v1 или v2, включены ли слоги.

### 2.2. Улучшения производительности

- **Быстрая пересборка зданий.** Правка плотности застройки одного района больше не пересчитывает всю карту — только здания.
- **Точечная коллизия.** Общая коллизионная сетка строится по минимальному размеру квартала среди районов — меньше наложений на границах.

### 2.3. Исправления

- Районы корректно получают типы (`center`, `commerce`, `residential` и т.д.) — раньше при генерации могла быть ошибка.
- Защита от зацикливания при поиске центра города.
- Мелкие чистки мёртвого кода.

## 3. Первый запуск

1. Скачай файл `Неон v0.9 3.html` (или как он у тебя называется).
2. Открой его двойным щелчком в браузере. Рекомендуется Chrome, Edge или Firefox последних версий.
3. Подожди 2–3 секунды — загрузятся шрифты (Exo 2, Russo One, Share Tech Mono). Сначала будет пусто, потом появится карта.
4. Если это первый запуск — сгенерируется случайный город автоматически.
5. Если раньше уже открывал — восстановится последний проект из локального хранилища браузера.

> **Совет.** Не очищай «данные сайта» и `localStorage`, если хочешь сохранить автосейв. Лучше периодически жми **Экспорт → Сохранить проект** и складывай JSON-файл в надёжное место.

### 4.1. Шапка (сверху)

| Элемент | Что делает |
|---|---|
| Логотип «НЕОН-КАРТОГРАФ» | Просто украшение |
| Поле «Название города» | Введи любое имя — оно попадёт на плашку экспорта |
| 🎲 (кнопка генерации) | Создать новый случайный город с новым зерном |
| ⛶ (фитинг) | Показать всю карту целиком |
| ↶ | Отменить `Ctrl+Z` — откатить последнее действие |
| ↷ | Повторить `Ctrl+Shift+Z` — вернуть отменённое |

### 4.2. Левая панель — инструменты

Вертикальный ряд иконок. Наведи курсор — появится подсказка.

**Навигация и природа:**

- **Курсор** — выбор и правка объектов.
- **Море** — кисть добавить воду.
- **Суша** — кисть убрать воду.
- **Горы** — кисть поднять рельеф.
- **Равнина** — кисть выровнять горы.
- **Сгладить** — кисть размыть резкие переходы воды/гор.
- **Река** — рисуешь ломаную → получается река.

**Город:**

- **Район** — клики задают полигон района.
- **Дорога** — рисуешь путь дороги.
- **Рельсы** — то же, но для железной дороги.
- **Улица (подпись)** — клик по улице → надпись вдоль неё.
- **Текст** — свободная надпись в любом месте.
- **Значок** — поставить якорь/корабль/башню/станцию.

**Объекты:**

- **Парк** — кисть рисовать зелёные зоны.
- **Свалка** — кисть рисовать пустыри и полигоны.
- **Объект** — поставить особое здание (монумент, капитолий и т.п.).
- **Рамка** — выделить прямоугольную область для PNG-экспорта.

### 4.3. Правая панель — вкладки

Семь вкладок сверху панели:

| Вкладка | Что внутри |
|---|---|
| Генерация | Параметры генерации нового города |
| Ландшафт | Кисти, слои, рисование рек |
| Город | Районы, дороги, значки, особые здания, кисти |
| Названия | Библиотеки имён, слоговый слой, регенерация |
| Цвета | Палитры, эффекты, слои |
| Подписи | Шрифты, авто-расстановка имён |
| Экспорт | PNG, PDF, сохранение проекта |

Ниже вкладок — карточка объекта. Появляется, когда что-то выделено на карте.

### 4.4. HUD (слева внизу холста)

Три числа:

- **Масштаб** — например, `100%`.
- **Население города** — например, `487 320 чел.`
- **Координаты курсора** — например, `1200, 830`.

### 4.5. Панель под холстом (drawbar)

Появляется, когда рисуешь что-то кистью или ломаной. Три кнопки:

- **Назад** — убрать последнюю точку.
- **Готово (Enter)** — завершить рисование.
- **Отмена (Esc)** — отменить целиком.

## 5. Базовый сценарий: сгенерировать город за 30 секунд

1. Открой вкладку **Генерация**.
2. Выбери тип поселения:
   - **Мегаполис** — до 3 млн населения, 9 районов.
   - **Город** — до 300 тыс., 6 районов.
   - **Деревня** — до 10 тыс., 2 района.
3. **Форма города** — оставь «Круглый» или попробуй «Вытянутый».
4. **Местность** — «Побережье» (самый живописный вариант).
5. **Целевое население** — поставь, сколько хочешь.
6. Нажми **«Сгенерировать»**.

Через 2–4 секунды появится готовый город. Если что-то не нравится — нажми 🎲 или «Сгенерировать» с новым зерном.

## 6. Вкладка «Генерация»

### 6.1. Тип поселения

Три кнопки-таблетки. Влияет на:

- Размер карты (1000×1150 / 1800×2050 / 2400×2760 px).
- Число районов.
- Количество дорог, магистралей, ж/д.
- Плотность ферм вокруг.

### 6.2. Местность

| Вариант | Что получается |
|---|---|
| Побережье | Море с одной стороны, пляжи, порт |
| Бухта | Море врезается «языком» |
| Река через город | Русло реки пересекает город |
| Озеро | Круглый водоём в центре |
| Равнина без воды | Сухой континентальный город |

### 6.3. Где море

Появляется только для «Побережье» и «Бухта». Варианты: случайно, справа, слева, сверху, снизу.

### 6.4. Форма города

- **Круглый** — классическая округлая застройка.
- **Вытянутый** — эллипс вдоль берега.
- **Линейный (трасса)** — узкая полоса вдоль главной дороги.
- **Сетка** — квадратный город с прямоугольными кварталами.
- **Двойной / Тройной / Рассеянный** — кластерные города с 2–4 ядрами.

### 6.5. Горные хребты (0–3)

Сколько горных массивов сгенерировать. `0` — ровная местность.

### 6.6. Реки (0–3)

Сколько рек протекает через город. `0` — без рек.

### 6.7. Размер квартала (10–40)

Больше — крупные кварталы с редкой сеткой. Меньше — плотная мелкая нарезка.

### 6.8. Число районов (1–14)

Сколько административных единиц.

### 6.9. Поля вокруг (0–60)

Сколько фермерских полей разбросать по карте вне города.

### 6.10. Целевое население

Желаемое население. От 500 до 3 000 000 человек. Реальное население показывается под ползунком.

### 6.11. Зерно (seed)

Число, определяющее генерацию. Одно и то же зерно = один и тот же город.

### 6.12. Кнопки действий

| Кнопка | Что делает |
|---|---|
| Сгенерировать | Создать новый город. Цвета и стиль сохраняются |
| Применить к текущему городу | Изменить только население (и плотность зданий) |
| Пересобрать улицы | Оставить районы, но дать им новые улицы |
| Новые названия районов | Только переименовать районы |

## 7. Вкладка «Ландшафт»

### 7.1. Кисть ландшафта

В левой панели выбери одну из кистей:

| Инструмент | Что делает | Цвет обводки курсора |
|---|---|---|
| Море | Добавляет воду | Бирюзовый |
| Суша | Убирает воду | Оранжевый |
| Горы | Поднимает рельеф | Фиолетовый |
| Равнина | Понижает рельеф | Оранжевый |
| Сгладить | Размывает переходы | Белый |

Как пользоваться:

1. Выбери кисть.
2. Выставь радиус (10–300) и силу (0.1–1).
3. Зажми левую кнопку и води по карте.

Карта обновляется на лету. После отпускания — финальная перерисовка через 1–2 секунды.

### 7.2. Быстрые действия

- **Убрать всю воду** — мгновенно высушить карту.
- **Убрать горы** — выровнять рельеф.

### 7.3. Реки

- Ползунок **«Ширина новой реки»** — задаёт ширину.
- Кнопка **«Нарисовать реку»** — включает инструмент.

Как рисовать реку:

1. Клик — точка.
2. Ещё клики — изгибы.
3. Двойной клик или `Enter` — готово.

### 7.4. Слои

Чекбоксы включения/выключения слоёв:

- Море и побережье
- Горы
- Реки
- Поля
- Парки
- Свалки
- Здания
- Подписи объектов

Отключение слоя не удаляет данные, только прячет.

- Трущобы
- Парк

### 8.7. Видимость слоёв

Полный список слоёв.

## 9. Вкладка «Названия»

Это главная вкладка для управления именами. Здесь же — новые функции слогового слоя и формата v2.

### 9.1. Активная библиотека

Показывает:

- Название библиотеки.
- Язык (если указан).
- Формат — `v1` (словарный) или `v2` (словарный + слоги).
- Состояние слогов: `слоги: вкл (базовые топонимы)` или `слоги: выкл`.

Под индикатором — три кнопки:

| Кнопка | Что делает |
|---|---|
| Перегенерировать все имена | Все имена меняются на новые (то же зерно) |
| Регенерировать с новым зерном | Все имена меняются + случайное зерно |
| Выключить слоги / Включить слоги | Быстрое переключение слогового слоя |
| Слоги только для улиц / Слоги для городов и рек | Переключение охвата: только улицы или плюс города и реки |

Пояснения про слоги:

- Слоговый слой **дополняет** словарный, а не заменяет. Если паттерн дал имя — оно используется. Слоги включаются, когда паттерн не справился (например, все варианты уже заняты).
- **Слоги для улиц** (по умолчанию при включённых слогах) — слоговые имена могут появляться у улиц, парков, свалок, монументов, но не у городов и рек.
- **Слоги для городов и рек** — дополнительно позволяет слоговому движку генерировать названия городов и рек. Полезно для экзотических языков.
- **Выключить слоги** — полностью отключает слоговый слой. Имена генерируются только из словарей.

### 9.2. Встроенные библиотеки

Три пресета:

- **Неон-нуар** — киберпанк-стилистика. Формат v2, слоги включены для городов и рек.
- **Славянский** — «Стрелецкая Слобода», «Улица Кузнецов», «Река Ока». Формат v2, слоги выключены (словарей достаточно).
- **Техно-утопия** — «Киберполис», «Центральный Хаб». Формат v2, слоги выключены.

Клик по пресету — применить ко всем названиям текущего города.

### 9.3. Своя библиотека

- **Сохранить библиотеку** — выгрузить текущую в JSON.
- **Загрузить свою библиотеку** — подсунуть свой файл.

Формат описан в отдельном документе `NAME-LIBRARY-BUILDER.md` — там же есть готовый промпт для нейросети, который по твоим референсам соберёт библиотеку под конкретный сеттинг.

## 15. Библиотеки имён — глубокое погружение

Это ядро разнообразия карт. Разберём подробно.

### 15.1. Как работает генерация имени

При создании имени для района, улицы, реки, парка, монумента или города происходит следующее:

1. **Выбор спецификации.** Для района — спецификация его типа. Для улицы — `street`. Для реки — `river`. И так далее.
2. **Сборка контекста.** Вычисляется контекст места: рельеф (море, река, горы), удалённость от центра, возраст застройки, ближайшая промышленность, сторона света.
3. **Выбор паттерна.** Из списка паттернов, подходящих под контекст, случайно выбирается один с учётом веса.
4. **Подстановка токенов.** Каждый `{token}` заменяется либо на слово из словаря, либо на значение контекста, либо на число.
5. **Проверка уникальности.** Если имя уже используется в этом городе — попробовать снова (до 30 раз).
6. **Слоговый fallback.** Если паттерны не справились — генерируется слоговое имя.

### 15.2. Контекстные токены

Эти токены не нужно объявлять в библиотеке — они подставляются автоматически, если у паттерна есть к ним доступ.

| Токен | Что подставляет | Пример |
|---|---|---|
| `{terrain_m}` / `{terrain_f}` | Рельеф места | «Морской», «Речная», «Горный» |
| `{rank_m}` / `{rank_f}` | Удалённость от центра | «Центральный», «Дальняя» |
| `{age_m}` / `{age_f}` | Возраст застройки | «Древний», «Новая» |
| `{industry_m}` / `{industry_f}` | Промышленный сосед | «Кузнечный», «Квантовая» |
| `{side_m}` / `{side_f}` | Сторона света | «Северный», «Восточная» |

Как это влияет на имена:

- Улица в порту получит `{terrain_f}` = «Морская» → возможное имя «Морская улица».
- Улица в трущобах получит `{age_m}` = «Кривой» → возможное имя «Кривой переулок».
- Монумент в центре получит `{rank_m}` = «Центральный» → возможное имя «Монумент Центральный».
- Река, текущая через район с портом, получит `{industry_f}` = «Рыбацкая» → возможное имя «Река Рыбацкая».

### 15.3. Слоговый слой

Для экзотических языков (фэнтези, sci-fi, ксеносы) словари быстро исчерпываются. Слоговый слой позволяет генерировать новые имена из «строительных блоков» языка.

Пример описания (способ A):

```json
"syllables": {
  "enabled": true,
  "baseToponyms": true,
  "min_syllables": 2,
  "max_syllables": 3,
  "onset": ["", "б", "бр", "в", "г", "д", "к", "пр", "ст", "ш"],
  "nucleus": ["а", "е", "и", "о", "у", "ы", "я"],
  "coda": ["", "", "н", "р", "л", "м", "с", "т", "кс"],
  "coda_freq": 0.35
}
```

Движок случайно комбинирует: `onset + nucleus + coda`, повторяет 2–3 раза, склеивает. Пример результата: «Вантрия», «Ксирен», «Стелоран».

Пример описания (способ B):

```json
"syllables": {
  "enabled": true,
  "baseToponyms": false,
  "recipes": ["CV", "CVC", "CVCV"],
  "C": ["б", "в", "г", "д", "к", "л", "м", "н", "р", "с", "т"],
  "V": ["а", "е", "и", "о", "у"]
}
```

`recipes` — шаблоны слогов. `C` — согласные. `V` — гласные.

### 15.4. Формат библиотеки v2

Полная структура:

```json
{
  "id": "my-world",
  "name": "Мой мир",
  "lang": "ru",
  "format": 2,
  "syllables": { "enabled": true },
  "district": { "generic": {}, "types": {} },
  "street": { "patterns": [] },
  "river": { "patterns": [] },
  "city": { "patterns": [] },
  "park": { "patterns": [] },
  "waste": { "patterns": [] },
  "special": { "capitol": {}, "monument": {} }
}
```

Маркер `"format": 2` говорит движку, что библиотека поддерживает слоги. Если его нет — библиотека считается v1 и слоговый слой у неё отключён.

### 15.5. Как сделать свою библиотеку

Самый простой путь — использовать промпт для нейросети. Документ `NAME-LIBRARY-BUILDER.md` содержит полное описание формата и готовый промпт: скопируй его вместе со своими референсами (примеры имён, стилевой промпт, цитаты из книги), и нейросеть соберёт валидный JSON.

Если хочешь собрать вручную:

1. Скопируй встроенную библиотеку как шаблон (в **Названия → Сохранить библиотеку**).
2. Открой JSON в текстовом редакторе.
3. Замени словари на свои.
4. Расширь паттерны под свой язык.
5. Если язык экзотический — добавь секцию `syllables` с `enabled: true`.
6. Сохрани файл.
7. Загрузи через **Названия → Загрузить свою библиотеку**.

Ошибки валидации показываются тостом — исправь и попробуй снова.

### 15.6. Правила валидации

Загрузчик проверяет:

- Корневой объект — не `null`, не массив.
- Есть хотя бы одно из `district`, `street`, `river`.
- Если `syllables.enabled: true`, то должно быть либо `onset + nucleus`, либо `recipes + C + V`.
- Каждый паттерн использует только те токены, которые объявлены в спецификации, в контексте или являются магическими (`{num}`).

Если хоть одно правило нарушено — библиотека не загрузится, а в тосте появится сообщение об ошибке.

## 16. Сценарии использования

### 16.1. «Мне нужен Нью-Йорк»

1. **Генерация → Мегаполис.**
2. **Местность → Побережье**, море справа.
3. **Форма → Сетка** (NYC).
4. **Сгенерировать.**

Получишь квадратный город с прямыми кварталами.

### 16.2. «Город вдоль берега»

1. **Генерация → Город.**
2. **Местность → Побережье**, море слева.
3. **Форма → Вытянутый.**
4. **Сгенерировать.**

### 16.3. «Город-утопия на Луне»

1. **Названия → Техно-утопия.**
2. Включить слоги (кнопка). Это даст городам и рекам более экзотичные имена.
3. **Цвета → Синька** или **Зелёный фосфор**.
4. **Ландшафт** → убрать всю воду, убрать горы.
5. **Генерация** → Местность «Равнина без воды», форма «Круглый».

### 16.4. «Средневековый город в славянском стиле»

1. **Названия → Славянский.**
2. Выключить слоги (кнопка) — славянский словарь богаче, слоги не нужны.
3. **Цвета → Янтарный терминал.**
4. **Генерация** → Деревня или Город, местность «Река через город».

### 16.5. «Ксеносный мир с чужим языком»

1. **Названия → Загрузить свою библиотеку** (сделанную через промпт).
2. В библиотеке должна быть секция `syllables` с `enabled: true` и `baseToponyms: true`.
3. Включить слоги, если не включены.
4. **Сгенерировать.**

Все имена — районы, улицы, реки, города — будут звучать на вымышленном языке.

### 16.6. «Нарисовать остров с нуля»

1. **Ландшафт → Море** → закрась всё.
2. **Суша** → нарисуй контур острова.
3. **Горы** — пара вершин.
4. Кисть **Парк** — лесные массивы.
5. Кисть **Свалка** — мусорные полигоны.
6. **Город → Нарисовать район** — 2–3 района.
7. **Подписи → Расставить названия.**

## 18. Советы и трюки

- **Одно зерно = один город.** Запиши понравившееся зерно.
- **Не бойся рисовать поверх.** Генератор — черновик.
- **Смена библиотеки** делает из киберпанка фэнтези без пересборки геометрии.
- **Слоги — секретное оружие для экзотики.** Включи их, если хочешь имена, не похожие ни на что реальное.
- **Контекст делает имена живыми.** Река, текущая через порт, не будет называться «Полевой».
- **Перед сложными правками** — жми `Ctrl+Z` часто. Стек 20 шагов.
- **Для чистого чертежа** выставь эффекты в 0 в «Цвета → Свечение и эффекты».
- **Для типографии** — PDF ≥ 200 dpi.
- **Своя библиотека** — через промпт. См. `NAME-LIBRARY-BUILDER.md`.
- **Автосохранение ≠ надёжное.** Раз в полчаса жми «Сохранить проект».

## 19. Ограничения текущей версии

- Только русский интерфейс.
- Только прямоугольные здания и L-формы. Полигональные (ангары, сложные) — в планах.
- Нет экспорта SVG. Только PNG и PDF.
- Нет кварталов как отдельной сущности.
- Свалка — не район.
- Население — оценка, не симуляция.
- Кросс-городская связность отсутствует. Города одного мира не помнят имена друг друга. Планируется в следующих версиях.
- Теги города отсутствуют. Город не «помнит», что он портовый или шахтёрский, и не влияет на имена через теги.
