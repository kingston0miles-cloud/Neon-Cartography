## 1. Что это и для чего

**НЕОН-КАРТОГРАФ** — браузерный генератор процедурных карт городов в неоново-киберпанк-стилистике. Работает полностью офлайн, в одном HTML-файле. Не требует установки, регистрации, сервера.

**Что умеет:**
- Генерировать город целиком: море, реки, горы, поля, районы, улицы, здания, парки, свалки, особые здания.
- Считать население — общее и по районам.
- Строить города разной формы: круглые, вытянутые, кластерные, «сетка».
- Давать процедурные имена всему: районам, улицам, рекам, паркам, монументам, городам.
- Работать с тремя встроенными «языковыми библиотеками» и загружать свои — в формате v1 (словарный) или v2 (словарный + слоговый).
- Использовать **контекст места**: имя улицы в порту отличается от имени улицы в трущобах.
- Генерировать базовые топонимы слоговым методом (города, реки).
- Рисовать вручную: насыпать остров, проложить реку, нарисовать район, поставить памятник.
- Экспортировать в PNG (до 8000 px) и PDF (A4–A0, до 300 dpi).
- Сохранять проекты в JSON и автоматически — в браузер.

**Кому подойдёт:** гейм-дизайнерам, писателям, авторам настолок, иллюстраторам, просто любителям карт.

## 2. Что нового в версии 2.0

Относительно предыдущей версии:

### 2.1. Расширенный движок имён

- **Формат библиотек v2.** Новый формат с опциональной секцией `syllables`. Старые библиотеки (v1) продолжают работать без изменений.
- **Слоговый слой.** Для экзотических языков, где словарь ограничен или отсутствует. Два способа описания: `onset + nucleus + coda` (точный) или `recipes + C + V` (компактный).
- **Контекст для всего.** Раньше контекст был только у районов. Теперь у улиц, рек, парков, монументов, дорог — тоже. Улица в порту получает «Морскую» через `{terrain_f}`, улица в трущобах — «Кривую» через `{age_m}`, монумент в центре — «Центральный» через `{rank_m}`.
- **Расширенные словари.** Прилагательных втрое больше, профессий — вчетверо, добавлены редкие и узкоспециальные слова.
- **Управление слогами в UI.** Кнопки «Выключить слоги» / «Включить слоги» и «Слоги только для улиц» / «Слоги для городов и рек» прямо во вкладке «Названия».
- **Индикатор формата.** Показывает, библиотека v1 или v2, включены ли слоги.

### 2.2. Улучшения производительности

- **Быстрая пересборка зданий.** Правка плотности застройки одного района больше не пересчитывает всю карту — только здания.
- **Точечная коллизия.** Общая коллизионная сетка строится по минимальному размеру квартала среди районов — меньше наложений на границах.

### 2.3. Исправления

- Районы корректно получают типы (`center`, `commerce`, `residential` и т.д.) — раньше при генерации могла быть ошибка.
- Защита от зацикливания при поиске центра города.
- Мелкие чистки мёртвого кода.

## 3. Первый запуск

1. Скачай файл `Неон v0.9 3.html` (или как он у тебя называется).
2. Открой его двойным щелчком в браузере. Рекомендуется **Chrome**, **Edge** или **Firefox** последних версий.
3. Подожди 2–3 секунды — загрузятся шрифты (Exo 2, Russo One, Share Tech Mono). Сначала будет пусто, потом появится карта.
4. Если это первый запуск — сгенерируется **случайный город** автоматически.
5. Если раньше уже открывал — восстановится **последний проект** из локального хранилища браузера.

> **Совет.** Не очищай «данные сайта» и localStorage, если хочешь сохранить автосейв. Лучше периодически жми **Экспорт → Сохранить проект** и складывай JSON-файл в надёжное место.
